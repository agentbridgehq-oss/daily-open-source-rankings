Daily Edition — Thursday, November 12, 2026

A Cage for Claude, Meta's Design System Still Climbing, and a Zelda Rebuild for the Switch 2 — Today's 10 Open-Source Breakouts

I'll be honest: today's board is the one where the agent wave starts putting guardrails on itself. The fastest-rising brand-new repo is a lightweight virtual machine built to cage Claude Code so nothing leaks over the network, and right behind it Meta's design system just stacked another 2,800 stars. Around them: a username hunter, a Zelda rebuild, and a finance app people self-host.

1. Lee-xeo/Claude-Cage (★4.4k, +1,855 today) — A lightweight VM made for Claude, and its whole pitch is one line: no network leaks, ever. It wraps your coding agent in a small virtual machine, works across platforms, handles multiple accounts, drives from your phone. Eleven days old — the first repo I'd install before letting agents loose on anything serious.

2. meta/astryx (★25.9k, +2,842 today) — Meta's open-source design system is still the biggest gainer on the board. It's the system Meta's own teams built on for eight years: 150+ accessible React components, brand theming, dark mode, templates, and a CLI, packaged so your agent can build with it too. Still the day's biggest gainer.

3. sherlock-project/sherlock (★110.4k, +2,393 today) — Type in a username and Sherlock checks it across 400+ social networks and tells you where it lives. It's been the standard OSINT tool in its lane for years, and it's still adding 2,400 stars a day. Never run it? The one-line install is the whole demo.

4. storytold/craft-anything (★29.3k, +2,260 today) — Point it at any app or game and it figures out how the thing works, then your agent rebuilds your version in the stack you pick. Pure Rust, 314 tools, clean-room inspection with real tools like Hopper and Ghidra. Third straight day on this board.

5. janestreet/agent_skills (★7.0k, +1,927 today) — Jane Street open-sourced the agent skills its own engineers use, and the dev world noticed: up 55% in a day. Skills are the quiet infrastructure of the agent wave: little instruction packs that teach your agent one job properly, from a firm famous for not shipping sloppy work.

6. debpalash/VoiceStudio (★108.8k, +1,861 today) — The fully local ElevenLabs alternative keeps climbing: voice cloning, voice design, video dubbing, dictation, transcription, and audiobooks in 646 languages, all on your own hardware. If you make anything with a voice in it, try this before paying for a cloud service.

7. pingdotgg/t3code (★57.8k, +1,299 today) — One control panel for every coding agent on your machine — Claude Code, Codex, and the rest — from any computer or phone. The T3 team's take on the agent dashboard. If your agents live on three machines and you check them from the couch, this is the app.

8. NotRexed/Hookshot (★8.3k, +1,179 today) — A native recompilation of The Legend of Zelda: Ocarina of Time for the Nintendo Switch 2. Six days old, and it's the kind of project that reminds you open source is, at heart, people rebuilding the things they love. Bring your own game files; the code does the rest.

9. we-promise/sure (★13.5k, +1,078 today) — A personal finance app you can self-host, with multiple clients and investment tracking built in. Finance apps are the category people keep taking back from subscriptions, and Sure's pitch — your money data stays on your machine — is landing exactly on time.

10. expo/exact (★3.2k, +905 today) — Write an app once and it runs natively on the web, macOS, iOS, and Linux — and an AI agent can build it, run it, see it, and test it on every one of them. Ten days old. Expo's bet: the next wave of apps gets built by agents, and Exact is the toolkit that makes it real.

That's the list for Thursday, November 12, 2026. The thread: agents are getting real jobs, and the tools around them are catching up — cages to keep them honest, skills to teach them the trade, dashboards to watch them work. Tomorrow's board will tell us which keeps climbing. My money's on the cage.
