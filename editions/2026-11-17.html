Daily Edition — Tuesday, November 17, 2026

1,900 Stars in One Day: Superpowers' 319K-Star Skills Framework Takes the Crown — Today's 10 Open-Source Breakouts

I'll be honest: I did not expect the biggest project on today's board to be a skills framework with 319,000 stars. But Tuesday, November 17, 2026 is the day the agent wave stopped being about the agents themselves and started being about what you teach them — half of today's ten are skills, frameworks for skills, or tools that grade skills.

Univer is still right there, holding on after yesterday's coronation, and the rest of the board splits between familiar giants and two brand-new arrivals: an 82-skill bug hunter and NVIDIA's own skill evaluator. Here's the ten.

1. obra/superpowers (★319.0k, +1.9K today) — An agentic skills framework and software development methodology that turns Claude Code into a disciplined partner: brainstorming that reads the project before asking questions, spec-writing, test-driven development, debugging. Three hundred nineteen thousand stars, and it just added another 1,900 in a day. When the biggest gainer on GitHub is a set of instructions for your agent, the skills layer isn't a side story anymore — it's the story.

2. dream-num/univer (★28.7k, +1.8K today) — The open-source office SDK is still the fastest-rising new idea on the board, a day after taking the crown: spreadsheets, docs, calculation and collaboration you drop into your own product, so people and AI agents can edit real files together. Google Docs as a building block, not a destination — and the stars keep coming.

3. morluto/rea (★465.3k, +1.6K today) — Point your agent at any app and learn how it works. It inspects native binaries through Hopper or Ghidra, JavaScript and Electron apps, .NET assemblies, and websites, then explains how a feature works — with the evidence, and the limits, behind each conclusion. The analysis runs locally. Four hundred sixty-five thousand stars, and it's still gaining 1,600 a day. At this point it's not a trend, it's a landmark.

4. ag-ui-protocol/ag-ui (★19.8k, +1.4K today) — An open, event-based protocol that plugs AI agents into frontend apps, so the agent and the interface finally speak the same language. Third straight day on the board, still pulling 1,400 stars a day. The plumbing every agent app ends up needing — and the board keeps agreeing.

5. janestreet/agent_skills (★9.8k, +1,128 today) — Jane Street's first public skill collection, built around the shared SKILL.md format. It ships one skill, socratic-tutor, which turns a language model into a strict personal tutor: it runs a diagnostic, draws a skill map from level 0 to 5, asks one question at a time, schedules spaced review and ends with an assessment. Copy the directory into your agent's skills folder. When a firm that guarded its edge for decades keeps publishing, I keep paying attention.

6. deepseek-ai/chat-demo (★4.4k, +1,066 today) — DeepSeek's static chat demo, powered by its API — a chat front end you can run yourself, pointed at DeepSeek's models. Four days old and already past four thousand stars. It's the simplest proof the harness era is real: the chat window is now a commodity, and the value moved to what you plug into it.

7. elementalsouls/Claude-BugHunter (★8.2k, +1,000 today) — A Claude Code skill bundle for bug hunting and external red-team work: 82 skills, 15 slash commands, 681 disclosed-report patterns curated across 24 core vulnerability classes, plus enterprise identity and infrastructure attack matrices. The number-one repo on GitHub Trending this morning, and the freshest face on today's board. Your agent, taught to think like an attacker before the real ones show up.

8. alibaba/open-code-review (★53.4k, +951 today) — Alibaba's internal AI code review tool, now open source — back on the board after a day off. Deterministic pipelines plus an LLM agent write precise line-level comments, backed by a built-in multi-language ruleset. This is the review process a company of Alibaba's size actually trusts, free to run yourself.

9. huamidev/GestaltX (★8.0k, +901 today) — A MobileGestalt editor for iOS 27.x, featuring region-code tweaks, device presets, and backups. The one pick today that has nothing to do with agents — and that's exactly why it stands out. Eight thousand stars in eight days for a tool that lets you reshape your own phone. The board isn't all agents, all the time, and the exceptions keep proving it.

10. NVIDIA/SkillEvaluator (★3.2k, +873 today) — NVIDIA's multi-tier framework for evaluating AI agent skills and plugins, with quality gates, semantic overlap detection, and synthetic evaluation dataset generation. Brand new, and the timing tells you everything: the day skills become the layer everyone builds on is the day someone has to grade them. NVIDIA just volunteered.

That's your ten. My pick? Claude-BugHunter — because an agent that can find the hole before a stranger does is the one I'd trust with real code, and 82 skills built on real disclosed reports is a curriculum, not a demo. If I've got an hour free, I'm installing superpowers first — 319,000 stars don't lie about what the community actually uses.

Tomorrow's edition lands Wednesday morning. The question I'm watching: Univer has held the top two days running — does the office SDK make it three, or does the skills wave crown a new name? And SkillEvaluator is brand new with NVIDIA behind it — if it doubles overnight, the grading era starts fast. Come back and see.
