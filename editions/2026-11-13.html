Daily Edition — Friday, November 13, 2026

Amazon Emulates AWS on Your Laptop, Chrome Teaches Your Agent the Modern Web, and Frame Generation Lands for Every GPU — Today's 10 Open-Source Breakouts

I'll be honest: today's board is the one where the big names stop watching the agent wave and start building for it. Amazon just shipped a local emulator for its own cloud APIs, Chrome handed your coding agent a curated guide to the modern web, and OpenAI put a security auditor in your terminal. Around them: a frame-generation tool for every GPU, a Slack alternative where your teammates are agents, and a design system that refuses to slow down. Friday, November 13, 2026 — here's the ten.

1. aws/aws-emulator (★6.2k, +2,133 today) — Amazon's local emulator of the AWS APIs, built for building and testing: start it, point the AWS CLI or your SDK at its endpoint, and work against emulated resources with no AWS account. Rust tests can embed one isolated instance per test through its HTTP client, and each release publishes per-service fidelity scores. The day your tests stop needing a cloud account is the day your whole workflow gets faster.

2. GoogleChrome/modern-web-guidance (★9.4k, +1,597 today) — A skill pack stewarded by the Chrome, Edge, Firefox and MDN teams that feeds your coding agent curated guides to the modern web platform: view transitions, container queries, the Popover API, built-in AI and more. Its CLI searches guides, pulls one by ID, and scans your codebase for legacy patterns worth replacing. Your agent finally learns the web as it is now, not as it was in its training data.

3. morluto/rea (★456.5k, +1,546 today) — Point your agent at any app and learn how it works. It inspects native binaries through Hopper or Ghidra, JavaScript and Electron apps, .NET assemblies, and websites, then explains how a feature works — with the evidence, and the limits, behind each conclusion. The analysis runs locally. Four hundred and fifty-six thousand stars, and it's still the fastest climber on the board. At this point it's not a trend, it's a landmark.

4. janestreet/agent_skills (★8.0k, +1,322 today) — Jane Street's first public skill collection, built around the shared SKILL.md format. It ships one skill, socratic-tutor, which turns a language model into a strict personal tutor: it runs a diagnostic, draws a skill map from level 0 to 5, asks one question at a time, schedules spaced review and ends with an assessment. Copy the directory into your agent's skills folder. When a firm that guarded its edge for decades keeps publishing, I keep paying attention.

5. meta/astryx (★27.1k, +1.8K today) — Meta's open-source, agent-ready design system, built inside the company over eight years: 150+ accessible React components, brand theming, dark mode, ready-made templates, and a CLI as one cohesive system. Fifth straight day on this board, still gaining nearly two thousand stars a day. Eight years of internal polish, now free for anyone to build on.

6. we-promise/sure (★14.4k, +944 today) — A personal finance app you can self-host, with multiple clients and investment tracking built in. Finance apps are the category people keep taking back from subscriptions, and Sure's pitch — your money data stays on your machine — is landing exactly on time. Third straight day on the board, and it keeps earning the spot.

7. apex-compute/ANR (★1.2k, +755 today) — A beta frame-generation tool from Apex Compute that installs into a game's folder, on GeForce, Radeon and Arc GPUs, Windows and Linux with Proton. A bundled recorder captures frame-generation inputs losslessly so the same frames replay through ANR FG or DLSS-G for comparison. Two days old, the smallest star count on today's board — and the one gamers will be talking about this weekend.

8. openai/codex-security (★12.8k, +754 today) — OpenAI's Codex Security CLI and TypeScript SDK for finding, validating, and fixing security vulnerabilities. Your agent finds the hole, proves it's real, and patches it — in the same run. The security audit that used to take a sprint now fits in a command.

9. vercel-labs/ui (★3.0k, +735 today) — A beta library from Vercel Labs: keyboard navigation, focus, selection, dismissal, popups, drag and drop and their ARIA become composable pieces, with adapters for React, Vue, Svelte, Solid and Web Components. Components are defined from behaviors and render identically across frameworks, and a bundled skill lets a coding agent learn the pattern. The boring parts of a UI, done once and done right.

10. agentes-chat/agentes-chat (★1.3k, +734/day) — An open-source, self-hosted Slack alternative where your team and AI agents work together in channels and DMs. Agents run on Claude, ChatGPT/Codex, Gemini or Grok, with MCP tools, their own computer and browser, routines, memory and approvals. Four days old and already the fastest-rising brand-new chat app on the board. The group chat where half the members actually do the work.

That's your ten. My pick? aws-emulator — because the moment your tests run against a local endpoint instead of a live cloud account, everything downstream gets cheaper and faster, and Amazon building it themselves is the tell. If I've got an hour free, I'm installing modern-web-guidance first, because an agent that writes modern code instead of patterns from three years ago is the difference between a demo and a product.
