Daily Edition — Sunday, November 22, 2026

9,848 Stars in Two Days: A GTA 6 Recompilation Claim Just Took Over GitHub — Today's 10 Open-Source Breakouts

I'll be honest: I did not expect the biggest project on GitHub this morning to be a repo that claims to recompile Grand Theft Auto 6 for the PC. It appeared two days ago, it's already past 9,800 stars, and the claim itself is doing most of the work — GTA 6 isn't out yet, so treat the pitch as a promise, not a fact. But the number is real, and it's the wildest thing on a board that otherwise belongs to the skills wave.

Sunday, November 22, 2026 is the day the chart split in two. The agent tools kept climbing — the bug hunter, the control panel, the security tester — and the internet's weird side showed up at the top anyway. Here's the ten.

1. ItsNotRexed/Leonida (★9,848, +5,800 today) — The repo says it's a native PC recompilation of the Xbox version of Grand Theft Auto 6. Two days old, nearly ten thousand stars, and a claim that deserves a raised eyebrow until someone shows the thing running. Recompilation projects are real — the community has done it for older games — but this one is moving faster than the evidence. Watch it, don't install it blind.

2. elementalsouls/Claude-BugHunter (★16,863, +1,803 today) — A Claude Code skill bundle for bug hunting and red-team work: 82 skills, 15 slash commands, 681 disclosed-report patterns across 24 vulnerability classes. Fourth day on the board and still gaining 1,800 a day. The skills wave has a security wing now, and it's not slowing down.

3. pingdotgg/t3code (★70,595, +1,800 today) — One control surface for the coding agents already on your machine: Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity and fx, driven from a phone, a web app or an Electron desktop app through your own subscriptions. Third appearance here, still pulling 1,800 a day.

4. anefzaoui/misterdownloadmanager (★16,307, +1,700 today) — The ultimate open-source, clean-room download manager written from scratch in pure Rust for Windows, Mac and Linux. No upload, no bundled junk — a from-scratch answer to the download managers everyone loved and then learned to distrust.

5. BaaRai/ARTEX (★15,650, +1,500 today) — A self-hosted, LLM-driven penetration testing platform, in an English mirror of the upstream project. A planner splits the goal into intents, workers run real tools, and every finding carries the captured request and response as evidence. Scope rules and approval gates keep autonomous actions inside authorized boundaries.

6. morluto/rea (★473,455, +1,300 today) — Point your agent at any app and learn how it works. It inspects native binaries through Hopper or Ghidra, JavaScript and Electron apps, .NET assemblies and websites, then explains how a feature works — with the evidence, and the limits, behind each conclusion. The analysis runs locally. Still gaining 1,300 a day at nearly half a million stars.

7. firecrawl/firecrawl (★206,584, +1,006 today) — Knowledge infrastructure to make your agents smarter: search, scrape and access 550+ data providers through one API. Back on the board after a break — the data layer underneath the agent wave keeps paying rent.

8. obra/superpowers (★323,816, +883 today) — An agentic skills framework and software development methodology that turns Claude Code into a disciplined partner: brainstorming that reads the project first, spec-writing, test-driven development, debugging. Three hundred twenty-three thousand stars and still adding nearly 900 a day.

9. HKUDS/CLI-Anything (★62,417, +769 today) — Make any software agent-native through a CLI. It generates CLIs from existing software so agents like Claude Code and Cursor can use it, and CLI-Hub lets you browse and install community-built ones. The quiet plumbing behind the agent wave — every tool your agent can't call is a tool it can't use.

10. zhouxiaoka/autoclip (★13,165, +683 today) — Open-source AI video clipping: paste one link and it cuts a long podcast, interview or course into short clips with subtitles, covers and posting copy, sized for TikTok, Reels and Shorts. The one pick today that speaks to creators, not coders — and 683 stars a day says plenty of them are listening.

That's your ten. My pick? Claude-BugHunter — because an agent that can find the hole before a stranger does is the one I'd trust with real code, and 82 skills built on real disclosed reports is a curriculum, not a demo. If I've got an hour free, I'm installing CLI-Anything first — every tool my agent can't reach is a job it can't do.

And Claude-BugHunter has held the top three for four days running; if it takes the crown, the security wing of the skills wave becomes the story. Come back and see.
