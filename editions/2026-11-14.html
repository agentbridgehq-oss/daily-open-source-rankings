Daily Edition — Saturday, November 14, 2026

Chrome's Web Guide Triples Its Lead, DeepSeek's Harness Leads the Day, and Alibaba Opens Its Code Reviewer — Today's 10 Open-Source Breakouts

I'll be honest: Saturday's board is the one where the agent wave stops asking permission and starts rebuilding the whole stack underneath it. Chrome's guide for coding agents just posted the biggest single-day gain on GitHub, DeepSeek's plugin harness pulled in three thousand stars before lunch, and Alibaba open-sourced the code reviewer its own engineers use at scale. Around them: a fleet manager for your coding agents, a menu-bar app that points any agent at any model, and a container runtime small enough to forget about. Saturday, November 14, 2026 — here's the ten.

1. GoogleChrome/modern-web-guidance (★12.5k, +3,355 today) — The skill pack stewarded by the Chrome, Edge, Firefox and MDN teams, and today it posted the biggest 24-hour gain on GitHub. Its CLI searches curated guides to the modern web platform — view transitions, container queries, the Popover API, built-in AI — pulls one by ID, and scans your codebase for legacy patterns worth replacing. Your agent finally learns the web as it is now, not as it was in its training data.

2. deepseek-ai/deepseek-harness (★280.9k, +3,136 today) — DeepSeek's agent harness, built on an everything-is-a-plugin architecture with a local Web UI. It leads the whole day's star count, and the reason is simple: the plugin system means anyone can bolt on new models, tools, and workflows — including free frontier models with no login and no API key. The harness is the platform; the plugins are the party.

3. morluto/rea (★458.8k, +2,351 today) — Point your agent at any app and learn how it works. It inspects native binaries through Hopper or Ghidra, JavaScript and Electron apps, .NET assemblies, and websites, then explains how a feature works — with the evidence, and the limits, behind each conclusion. The analysis runs locally. Fourth appearance on this board in six days, and it's still gaining two thousand stars a day. At this point it's not a trend, it's a landmark.

4. alibaba/open-code-review (★51.1k, #1 on GitHub Trending today) — Alibaba's internal AI code review tool, now open source. Deterministic pipelines plus an LLM agent write precise line-level comments, backed by a built-in multi-language ruleset. It's the top-trending repo on GitHub this morning, and the pitch is hard to argue with: the review process a company of Alibaba's size actually trusts, free to run yourself.

5. stablyai/orca (★124.7k, +1,287 today) — Orca runs a fleet of coding agents — Claude Code, Codex, and the rest — on your own subscription, from desktop, mobile, or a remote runtime. One fleet, one bill, every agent you already pay for. The multi-agent era has a staffing problem, and Orca is applying for the job.

6. pingdotgg/t3code (★60.1k, +1,269 today) — One control panel for every coding agent on your machine — Claude Code, Codex, and the rest — from any computer or phone. The T3 team's take on the agent dashboard, back on the board after its November 12 debut. If your agents live on three machines and you check them from the couch, this is the app.

7. yetone/magpie (★36.4k, +829 today) — Every agent's model, in one place. Magpie sits in your menu bar and lets you run Codex on DeepSeek, Claude Code on Kimi, and whatever comes next — same agent, cheaper model, no rewiring. Fifty-one days old and already the day's fastest-rising brand-new idea in model routing. The subscription stack is getting unbundled, one menu bar at a time.

8. openai/codex-security (★13.4k, +751 today) — OpenAI's Codex Security CLI and TypeScript SDK for finding, validating, and fixing security vulnerabilities. Your agent finds the hole, proves it's real, and patches it — in the same run. Second straight day on the board, and the security audit that used to take a sprint still fits in a command.

9. libracoder/kiri (★2.7k, +585 today) — A small, fast container runtime for macOS, Windows, and Linux, written in Rust. Twelve days old, the smallest star count on today's board — and the one with the clearest pitch: containers without the weight. Docker's shadow is long, but two thousand seven hundred stars in twelve days says plenty of people want something lighter.

10. CopilotKit/OpenBot (★12.2k, +298 today) — Open-source AI coworkers that each get a computer of their own: a browser, files, and tools, with every action decided before it happens and recorded after. Bring any AG-UI agent. The governance angle is the whole point — an agent that shows its work before it does the work is one you can actually trust with the keys.

That's your ten. My pick? modern-web-guidance — because the biggest gain on the board is also the most practical one: an agent that writes modern code instead of patterns from three years ago is the difference between a demo and a product. If I've got an hour free, I'm installing magpie first, because pointing the agents I already use at models that cost a fraction of the price pays for itself by lunch.
